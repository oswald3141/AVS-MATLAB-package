# AVS package
This is a MATLAB package with general-purpose and DSP utilities.

## Subpackages
- **dsp** Basic functions and classes for DSP.
- **signal_analysis** Functions and classes for signals manipulation and
analysis in time and frequency domain.
- **validators** Arguments validation functions.
- **misc** General-purpose functions simplifying programming.

## Installation
Add `src/avs` folder into the MATLAB's Path with all its subfolders.
